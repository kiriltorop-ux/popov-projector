# Проверка «Город говорит» · 21 ноября 2026

Рабочая версия из чата «Перевести сканирование QR в чат» подключена к локальной станции. Кнопка «Сканировать QR-код» в карточке персонажа и в нижнем меню открывает один и тот же сканер. После распознавания QR можно открыть чат станции.

## Как повторить

В каталоге mobile выполните `npm run build` и `npm test`. Запустите `node tests/serve.mjs` и затем `npm run test:browser` для автономной версии. Для запущенной станции выполните `GG_TEST_URL=http://127.0.0.1:18776/ npm run test:mobile`. Настройка Chromium описана в README этого каталога.

В этом запуске прошли 8 модульных тестов клиента, 17 сценариев автономной версии в Chromium, 7 групп мобильных проверок и 39 тестов действующего сервера. Для проверки настоящего QR использовались синтетические видеокадры и локальный API. Прямой запрос к Wi-Fi-адресу из тестовой среды не прошёл, поэтому браузер обращался к станции через loopback с сохранением адреса страницы. Телефон в сети площадки в этой проверке не участвовал.

Политика безопасности действующего сервера разрешает тайлы OpenStreetMap и ограничивает загрузку спутниковых снимков Esri. При недоступности тайлов приложение показывает локальную схему и сохраняет доступ к пяти точкам.
