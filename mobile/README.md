# Город говорит

Мобильное приложение с цифровыми гидами Нижнего Новгорода.

**Сайт:** https://antony502189-max.github.io/gorod-govorit/

## Попов на площадке

QR на проекции открывает чат станции. Центральная кнопка QR в нижнем меню открывает сканер. В чате проектора доступны три вопроса. Ответы, очередь и статусы приходят от сервера, а звук воспроизводится на компьютере с проектором.

Откройте персонажа на главной или на карте и нажмите «Сканировать QR-код» на его странице. Откроется сканер. Наведите камеру на QR проектора, чтобы открыть чат станции.

Кнопка с микрофоном открывает запись или загрузку аудиофайла. После распознавания текст можно исправить перед отправкой. Для записи из браузера требуется HTTPS, на локальном HTTP доступны загрузка файла и текстовый вопрос. Настройка Mac и Windows описана в [инструкции к проектору](../README.md#qr-станция-с-мобильным-приложением).

Статическая сборка сохраняет локальный демонстрационный диалог Попова. Остальные гиды и студия используют локальные материалы.

## Мобильный интерфейс

Основной интерфейс рассчитан на телефон: небольшие скругления 4–6 px, списки гидов, нижняя навигация и области нажатия от 44 px. Студия разделена на вкладки «Образ», «Знания» и «Просмотр» с сохранением черновиков. Диалог открывается в текстовом чате. Поле ввода учитывает VisualViewport и появление клавиатуры. У маршрута — компактный выбор и закреплённые действия.

Мобильные проверки: `npm run test:mobile` при запущенном локальном сервере. Размеры 320×568, 360×740, 390×844 и 430×932. Клавиатурная раскладка проверяется уменьшением viewport и моделированием события VisualViewport; это не заменяет испытание на физическом iPhone.

## Возможности

- Поиск мест, персонажей и маршрутов, карточки городских достопримечательностей.
- Три стартовых гида и создание своих: имя, образ, картинка, роль, голос и база знаний.
- Ответы по материалам с указанием источника; отказ, если сведений недостаточно.
- Прогулка по кремлю и набережной на 2 часа, короткие маршруты на 30–60 минут, фильтр, сохранение и скачивание плана.
- Экран посетителя, полноэкранный режим, озвучка при наличии русского голоса браузера.
- Экспорт и импорт проекта, черновики и защита от конфликтов между вкладками.
- Адаптивные экраны, локальный Inter, иконки Phosphor и фотографии с атрибуцией.

## GitHub Pages

Сайт целиком статический, исходники и публикуемые файлы находятся в `docs/`.
В Settings → Pages выбрано **Deploy from a branch**, **main**, **/docs**.
Интерфейс использует Vue 3.5.45. Браузерная сборка Vue и лицензия MIT находятся в `docs/vendor/`. Для публикации и запуска статического сайта достаточно каталога `docs/`. Ключи, установка npm-пакетов и подключение к CDN не нужны.
Все ресурсы используют относительные пути и работают в подпапке `/gorod-govorit/`.

Данные сохраняются в **IndexedDB этого браузера**. Рабочие области разных браузеров и устройств независимы. Для переноса используйте «Скачать проект» и «Резервная копия» в студии гида. Очистка данных сайта удаляет локальную копию. Публикация исходников не публикует созданных пользователем персонажей или их материалы.

Диалог отвечает по базе знаний с помощью BM25. Карточки с источниками видны в чате. Вкладка «Карта» зарезервирована для будущего раздела. Гостиница «Волга» и её условия вымышлены.

## Диалог с персонажем

Гиды отвечают в текстовом чате. Озвучить отдельный ответ можно кнопкой под ним. Озвучка использует голоса браузера. Переписка разделена по персонажам и живёт до перезагрузки вкладки.

По умолчанию сцена показывает существующий портрет. Для 3D добавьте GLB в `docs/assets/avatars/` и впишите относительный путь по ID персонажа в `docs/avatar-models.mjs`. Образ должен смотреть вдоль +Z. Поддерживаются клип `Idle` для ожидания и `Speaking` или `Talk` для речи. Если клипа речи нет, можно использовать морф `jawOpen`, `mouthOpen` или `viseme_aa` либо узел `Jaw`. Движение запускается на время озвучки. Загруженная в студии картинка имеет приоритет. При отсутствии WebGL или недоступности файла остаётся обычный портрет. Рендер использует локальную сборку Three.js 0.180.0, лицензия в `docs/vendor/Three-LICENSE.txt`.

## Локальная разработка

Нужен Node.js 22 или новее.

```sh
node tests/serve.mjs
# http://127.0.0.1:4176/gorod-govorit/
node --test tests/*.test.mjs
npm install
npm run build
```

Если установлены Python-окружение и голосовая модель из проекта проектора, локальный предпросмотр распознаёт диктовку через Whisper на этом компьютере. На статическом сайте диктовка использует распознавание речи браузера.

Сборка предкомпилирует Vue-шаблоны в `docs/vue-renders.mjs`, копирует `docs/` в `dist/` и проверяет пути ресурсов. Обновляйте сгенерированный модуль после правок шаблонов. Станция и статический сайт загружают его из `docs/`. GitHub Pages публикует `docs/` напрямую.

Проверка интерфейса:

```sh
npm install
npx playwright install chromium
node tests/serve.mjs
# в другом терминале
npm run test:browser
```

Можно задать `GG_TEST_URL` для проверки опубликованной версии и `GG_BROWSER_EXECUTABLE` для установленного Chromium. Тесты создают только локальные данные в отдельном профиле браузера. Проверяются диалог, новые материалы и изображения, сохранение, работа без API, импорт/экспорт, конфликт вкладок, экран посетителя, клавиатура, экраны 320 и 390 px.
