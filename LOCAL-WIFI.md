# Локальный запуск Windows

`start-windows.cmd` устанавливает зависимости и запускает нативного Попова. Если
существует `work/lan-tls/settings.json`, он также запускает локальный HTTPS-шлюз.
Для HTTPS нужен установленный Node.js. Готовность портов проверяется; ошибки
запуска записываются в `work/projector-launch.log` и `work/https-launch.log`.

## Первая настройка HTTPS

```powershell
.server-venv/Scripts/python.exe -m pip install -r server/requirements-lan.txt
.server-venv/Scripts/python.exe scripts/setup-lan-tls.py --host YOUR_WIFI_IPV4
```

Добавьте в локальную `.env`:

```dotenv
POPOV_LAN_HOST=YOUR_WIFI_IPV4
POPOV_LOCAL_PUBLIC_URL=https://YOUR_WIFI_IPV4:18777
```

Перезапустите Попова через `start-windows.cmd`. На телефоне откройте
`http://YOUR_WIFI_IPV4:18778/` и выполните установку открытого сертификата ЦС.
Приложение находится по адресу `https://YOUR_WIFI_IPV4:18777/`. Камера и микрофон
работают в браузере после установки сертификата и выдачи соответствующего
разрешения. Телефон и ноутбук должны быть в одной Wi-Fi сети.

Закрытые ключи находятся только в `work/lan-tls/`. Эта папка исключена из Git и
Docker-контекста. Повторная настройка с тем же адресом сохраняет сертификат.
При смене IP подготовка завершается с объяснением. Для сознательной замены ЦС
используется `--renew-ca`; прежние файлы сохраняются в локальном резервном каталоге,
а новый открытый сертификат потребуется снова установить на устройствах.

## Границы текущей реализации

- Серверная цепочка LLM → озвучка → проектор поддерживает Попова и Минина.
  Для Минина задайте `POPOV_GUIDE=minin` в `.env` перед запуском.
- Русские голоса Piper — Денис для Попова и Дмитрий для Минина. Для английского используется доступный голос Windows
  с резервным Edge TTS, для китайского — Edge TTS. Облачные сервисы требуют интернет.
- Ротация QR ограничивает новый вход. Уже допущенная cookie-сессия получает
  три успешных запроса без таймера. У Минина показ истории использует один запрос.
- Привязка cookie к User-Agent не доказывает физическое присутствие сама по себе.
- Docker и нативная сборка macOS отдельно не подтверждены на этом Windows-ПК.
